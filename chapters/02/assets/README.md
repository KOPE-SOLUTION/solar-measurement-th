# ที่มาและเครดิตภาพ — บทที่ 2 (EP 2)

[กลับชุดภาพ](../visual-guide.md) · [กลับบทเรียน](../README.md)

ภาพทั้ง **7 ภาพ** เป็นงานต้นฉบับของ **KOPE SOLUTION** สร้างเมื่อ 18 พฤศจิกายน 2026 เป็นแผนภาพเวกเตอร์ SVG และกราฟคำนวณ แล้วเรนเดอร์เป็น PNG ขนาด **1600 × 900 px (16:9)** ด้วย System.Drawing ใช้ฟอนต์ Leelawadee UI ไม่ใช่ภาพถ่ายสินค้า ข้อมูลวัดจริง หรือภาพจากหน่วยงานที่อ้างอิง

| ภาพ PNG | ต้นฉบับ SVG | เนื้อหาและเงื่อนไข |
|---|---|---|
| [direct-and-diffuse.png](direct-and-diffuse.png) | [SVG](direct-and-diffuse.svg) | เส้นทางตรงกับเส้นทางกระเจิง ลูกศรไม่แทนสัดส่วนพลังงาน |
| [ghi-dni-dhi.png](ghi-dni-dhi.png) | [SVG](ghi-dni-dhi.svg) | ปริมาณและระนาบของ GHI, DNI และ DHI |
| [zenith-projection.png](zenith-projection.png) | [SVG](zenith-projection.svg) | มุมเซนิท 60°; ตัวอย่างสมมติ 800 × cos(60°) = 400 W/m² |
| [ghi-components-example.png](ghi-components-example.png) | [SVG](ghi-components-example.svg) | กราฟแท่งสเกลเดียวกัน ตรึง DNI = 800 และ DHI = 100 W/m²; GHI = 900, ≈ 793, 500 W/m² ที่ θz = 0°, 30°, 60°; ปัดตัวเลขเป็นจำนวนเต็ม ไม่ใช่เส้นเวลาระหว่างวัน |
| [measurement-setups.png](measurement-setups.png) | [SVG](measurement-setups.svg) | รูปหลักการเครื่องมือและการจัดวาง ไม่ใช่แบบสินค้าหรือคำยืนยันรุ่นในสถานี |
| [horizontal-vs-poa.png](horizontal-vs-poa.png) | [SVG](horizontal-vs-poa.svg) | แนวราบเทียบระนาบเอียง และส่วนสะท้อนจากพื้นดิน |
| [quiz-components.png](quiz-components.png) | [SVG](quiz-components.svg) | โจทย์สมมติสามข้อ เฉลยอยู่ในบทเรียน; ข้อ 1–2 ให้ข้อมูลเวลาและตำแหน่งเดียวกัน ดวงอาทิตย์อยู่เหนือขอบฟ้า |

สีส้มแทนรังสีตรง สีเขียวอมฟ้าแทนรังสีกระจาย และสีเขียวในภาพระนาบเอียงแทนส่วนสะท้อนจากพื้น ลูกศรและเครื่องมือเป็นภาพอธิบาย ไม่ใช้ขนาดพิกเซลคำนวณปริมาณรังสี กราฟแท่งใช้ความสูงตามค่าคำนวณจริง

หลักการอ้างอิง [กรมอุตุนิยมวิทยา — การแผ่รังสี](https://www5.tmd.go.th/info/การแผรงส), [Australian Bureau of Meteorology — Solar and Terrestrial Radiation](https://www.bom.gov.au/climate/austmaps/solar-radiation-glossary.shtml) และเอกสาร Sandia PVPMC ที่ระบุแยกตามหัวข้อใน [บทเรียน](../README.md) ตัวเลข การจัดภาพ และโจทย์เป็นของผู้จัดทำ
