# เจาะลึกการวัดรังสีดวงอาทิตย์

ซีรีส์ความรู้ภาษาไทยเรื่องการวัดรังสีดวงอาทิตย์ ตั้งแต่พื้นฐาน เซ็นเซอร์ เครื่องอ้างอิง การปรับเทียบ ไปจนถึง Clear Sky และการวิเคราะห์ข้อมูลจำลอง

เริ่มเรียนจากความหมายของตัวเลข แล้วค่อยพัฒนาไปสู่การเปรียบเทียบ การออกแบบการทดสอบ และการตรวจยืนยันผล ตัวอย่างทั้งหมดเป็นข้อมูลสมมติทั่วไป ใช้ชื่ออุปกรณ์ว่า **เซ็นเซอร์ทดสอบ** และ **เครื่องอ้างอิง**

## หลักการของซีรีส์

- ใช้ข้อมูลจำลองและสถานการณ์ทั่วไปเท่านั้น
- แยกความรู้จากแหล่งอ้างอิง สมมติฐานของตัวอย่าง และคำแนะนำของผู้จัดทำ
- ตรวจอ่านเอกสารปฐมภูมิหรือเอกสารทางการที่ใช้จริง และวางลิงก์ใกล้ข้ออ้าง
- แสดงหน่วย ตัวหาร ช่วงเวลา และจำนวนข้อมูลที่ใช้ให้ชัดเจน
- ระบุเกณฑ์สมมติ เช่น ±10% ว่าเป็นเกณฑ์ของโจทย์ ไม่ใช่มาตรฐานสากล
- แยกกฎ ratio เพื่อการสอนออกจากวิธี Reno–Hansen และระบุ implementation/เวอร์ชันเมื่อใช้โค้ด
- ไม่ตีความ alpha ของตัวตรวจจับ Clear Sky ว่าเป็น Gain ของเซ็นเซอร์โดยอัตโนมัติ

## โครงสร้าง

```text
chapters/
  01/                  บทพูดพื้นฐานและ description
  04/                  บทเปรียบเทียบกับเครื่องอ้างอิง

SERIES_PLAN.md          ลำดับเนื้อหาบท 01–12
REFERENCES.md           แหล่งอ้างอิงและขอบเขตการใช้

```

ตัวอย่างคำนวณใช้ Python 3 และ standard library:

```sh
python examples/basic_calculations.py
```

## ขั้นตอนผลิตแต่ละตอน

กำหนดคำถามของผู้เรียน → ตรวจแหล่งอ้างอิง → เขียนบทและข้อมูลสมมติ → ตรวจตัวเลข → เตรียมภาพ → ซ้อมอ่าน → อัดเสียง → ตัดต่อ → ตรวจเนื้อหาและหน่วย → ปรับ chapter timestamps

การอัปโหลดหรือเผยแพร่วิดีโอทำเมื่อได้รับคำสั่งแยกต่างหาก
