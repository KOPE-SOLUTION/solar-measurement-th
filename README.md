# เจาะลึกการวัดรังสีดวงอาทิตย์

เรียนรู้การวัดแสงแดดจากพื้นฐาน อ่านหน่วยให้เข้าใจ แล้วค่อยไปสู่เซ็นเซอร์ เครื่องอ้างอิง และการวิเคราะห์ข้อมูล

## สารบัญบทเรียน

ขณะนี้มีบทเรียนฉบับอ่านของบทที่ 1 ส่วนบทที่ 2–12 ยังเป็นแผนเนื้อหา เลือกเปิดอ่านจากตารางได้เลย

| บท | จะเรียนเรื่องอะไร | เปิดอ่าน / สถานะ |
|---|---|---|
| **1** | **เราวัดอะไรเมื่อบอกว่าแดดแรง — W/m² และ Wh/m²** | **[อ่านบทที่ 1](chapters/01/README.md)** |
| 2 | รังสีตรง รังสีกระจาย และ GHI/DNI/DHI | อยู่ในแผน |
| 3 | จากเซ็นเซอร์สู่ข้อมูล: หน่วย เวลา และข้อมูลประกอบ | อยู่ในแผน |
| 4 | เปรียบเทียบกับเครื่องอ้างอิงและคิดเปอร์เซ็นต์ | อยู่ในแผน |
| 5 | จับคู่ข้อมูล เวลา และช่วงเฉลี่ย | อยู่ในแผน |
| 6 | แสงนิ่งกับฟ้าใสต่างกันอย่างไร | อยู่ในแผน |
| 7 | ปรับค่า Gain/Offset และตรวจยืนยันผล | อยู่ในแผน |
| **8** | **Ineichen–Perez — แบบจำลองรังสีเมื่อท้องฟ้าใส (Clear Sky)** | อยู่ในแผน |
| 9 | ตรวจจับช่วงฟ้าใสด้วย Reno–Hansen/pvlib | อยู่ในแผน |
| 10 | ออกแบบการทดสอบ เกณฑ์ตัดสิน และความไม่แน่นอน | อยู่ในแผน |
| 11 | วิเคราะห์เงาบัง มุมรับแสง เวลาหน่วง และอาการผิดปกติ | อยู่ในแผน |
| 12 | ฝึกกระบวนการทั้งหมดด้วยข้อมูลจำลอง | อยู่ในแผน |

[ดูรายละเอียดแผนซีรีส์ทั้งหมด](SERIES_PLAN.md)

## คำอ่านที่พบในซีรีส์

| คำศัพท์ | คำอ่านไทยโดยประมาณ | ความหมาย / บทที่เกี่ยวข้อง |
|---|---|---|
| Solar Radiation | โซ-เลอร์ เร-ดี-เอ-ชัน | รังสีดวงอาทิตย์ — บทที่ 1 |
| Net Radiation | เน็ต เร-ดี-เอ-ชัน | รังสีสุทธิ — บทที่ 1 |
| **Ineichen–Perez** | **อิ-ไน-เคิน–เป-เรซ** | แบบจำลองรังสีเมื่อท้องฟ้าใส — บทที่ 8 |

**Ineichen–Perez** ใช้คำนวณรังสีในสภาวะท้องฟ้าใส โดย `pvlib.clearsky.ineichen` ให้ค่า GHI, DNI และ DHI จากข้อมูลมุมดวงอาทิตย์ มวลอากาศ ความขุ่นมัวแบบ Linke และอินพุตที่เกี่ยวข้อง ค่าที่ได้เป็นผลของแบบจำลองตามสมมติฐาน ([เอกสาร pvlib](https://pvlib-python.readthedocs.io/en/stable/reference/generated/pvlib.clearsky.ineichen.html)) เนื้อหาเต็มอยู่ในแผนบทที่ 8

คำอ่านไทยใช้ช่วยอ่าน ไม่ใช่สัทอักษร โดยเฉพาะ Ineichen ซึ่งเป็นชื่อเฉพาะ ยังไม่ได้ยืนยันการออกเสียงจากเจ้าของชื่อ

## แหล่งอ้างอิงไทยและสากล

บทที่ 1 ใช้เอกสารของ **กรมควบคุมมลพิษ** เรื่องรหัส SRAD/NRAD, **กรมอุตุนิยมวิทยา** เรื่องรังสี และ **สถาบันมาตรวิทยาแห่งชาติ (มว.)** ผู้เผยแพร่ VIM ฉบับไทย–อังกฤษ ควบคู่กับเอกสารของ NIST, Australian Bureau of Meteorology และ FAO

วางลิงก์ไว้ใกล้คำอธิบายในบทเรียน และระบุว่าแต่ละเอกสารใช้รองรับเรื่องใดใน [รายการแหล่งอ้างอิง](REFERENCES.md) ตัวอย่างและแบบฝึกหัดเป็นข้อมูลสมมติของผู้จัดทำ

<details>
<summary>ตัวอย่างคำนวณด้วย Python</summary>

[เปิดตัวอย่างคำนวณ](examples/basic_calculations.py) ใช้ Python 3 และ standard library

```sh
python examples/basic_calculations.py
```

</details>

<details>
<summary>หลักการจัดทำเนื้อหา</summary>

- ใช้ข้อมูลสมมติทั่วไปและชื่ออุปกรณ์ว่า **เซ็นเซอร์ทดสอบ** กับ **เครื่องอ้างอิง**
- แยกข้อเท็จจริงที่มีแหล่งอ้างอิงออกจากสมมติฐาน ตัวอย่าง และคำแนะนำ
- เลือกแหล่งปฐมภูมิหรือเอกสารทางการทั้งไทยและสากลให้ตรงกับข้ออ้าง และตรวจอ่านส่วนที่ใช้
- ระบุหน่วย ตัวหาร ช่วงเวลา และเงื่อนไขของสูตร
- ระบุเกณฑ์สมมติ เช่น ±10% ว่าเป็นเกณฑ์ของโจทย์ ไม่ใช่มาตรฐานสากล
- แยกกฎ ratio เพื่อการสอนออกจาก Reno–Hansen และไม่ตีความ alpha ของตัวตรวจจับ Clear Sky ว่าเป็น Gain ของเซ็นเซอร์โดยอัตโนมัติ

[แนวทางสำหรับผู้แก้ไขเนื้อหา](AGENTS.md)

</details>
