# เจาะลึกการวัดรังสีดวงอาทิตย์

เรียนรู้การวัดแสงแดดจากพื้นฐาน อ่านหน่วยให้เข้าใจ แล้วค่อยไปสู่เซ็นเซอร์ เครื่องอ้างอิง และการวิเคราะห์ข้อมูล

## [เริ่มอ่านบทที่ 1 → เราวัดอะไรเมื่อบอกว่าแดดแรง](chapters/01/README.md)

เริ่มที่ลิงก์ด้านบนได้เลย เป็นบทเรียนฉบับอ่านพร้อมตัวอย่างและแบบฝึกหัด ใช้เพียงการคูณ หาร และแปลงนาทีเป็นชั่วโมง เปิดอ่านบน GitHub ได้โดยไม่ต้องติดตั้งโปรแกรม

บทแรกเริ่มจากคำถามเรื่อง **SRAD / NRAD** ที่พบในบริบทตู้ตรวจวัดคุณภาพอากาศและอุตุนิยมวิทยา แล้วชวนหาคำตอบว่า **800 W/m² หมายถึงอะไร**, ต่างจาก **Wh/m²** อย่างไร และทำไมค่าตอนเที่ยงเพียงจุดเดียวจึงยังบอกพลังงานทั้งวันไม่ได้

## ควรอ่านตามลำดับไหน

1. **อ่าน [บทที่ 1](chapters/01/README.md)** ตั้งแต่ต้น แล้วลองทำแบบฝึกหัดก่อนเปิดเฉลย
2. **ต่อด้วยบทที่ 2 และ 3 เมื่อมีเนื้อหา** สองบทนี้ยังอยู่ในแผน ดูหัวข้อได้ในตารางด้านล่าง
3. **หากสนใจเรื่องเปอร์เซ็นต์เทียบเครื่องอ้างอิง** มี [ชุดบทที่ 4 ตอนที่ 1](chapters/04/01-recording-pack.txt) ให้อ่านเพิ่มเติมได้ โดยยังอยู่ในรูปบทพูดเตรียมอัด

ขณะนี้มีบทเรียนฉบับอ่านของบทที่ 1 และชุดเตรียมอัดบทที่ 4 ตอนที่ 1 ส่วนบทอื่นยังเป็นแผนเนื้อหา

## แหล่งอ้างอิงไทยและสากล

บทที่ 1 ใช้เอกสารของ **กรมควบคุมมลพิษ** เรื่องรหัส SRAD/NRAD, **กรมอุตุนิยมวิทยา** เรื่องรังสี และ **สถาบันมาตรวิทยาแห่งชาติ (มว.)** ผู้เผยแพร่ VIM ฉบับไทย–อังกฤษ ควบคู่กับเอกสารของ NIST, Australian Bureau of Meteorology และ FAO

วางลิงก์ไว้ใกล้คำอธิบายในบทเรียน และระบุว่าแต่ละเอกสารใช้รองรับเรื่องใดใน [รายการแหล่งอ้างอิง](REFERENCES.md) ตัวอย่างและแบบฝึกหัดเป็นข้อมูลสมมติของผู้จัดทำ

<details>
<summary>หลักการจัดทำเนื้อหา</summary>

- ใช้ข้อมูลสมมติทั่วไปและชื่ออุปกรณ์ว่า **เซ็นเซอร์ทดสอบ** กับ **เครื่องอ้างอิง**
- แยกข้อเท็จจริงที่มีแหล่งอ้างอิงออกจากสมมติฐาน ตัวอย่าง และคำแนะนำ
- เลือกแหล่งปฐมภูมิหรือเอกสารทางการทั้งไทยและสากลให้ตรงกับข้ออ้าง และตรวจอ่านส่วนที่ใช้
- ระบุหน่วย ตัวหาร ช่วงเวลา และเงื่อนไขของสูตร
- ระบุเกณฑ์สมมติ เช่น ±10% ว่าเป็นเกณฑ์ของโจทย์ ไม่ใช่มาตรฐานสากล
- แยกกฎ ratio เพื่อการสอนออกจาก Reno–Hansen และไม่ตีความ alpha ของตัวตรวจจับ Clear Sky ว่าเป็น Gain ของเซ็นเซอร์โดยอัตโนมัติ
